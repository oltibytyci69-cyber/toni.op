# TONI O.P. Website — Updated

This is a pure static website for GitHub Pages.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `content.js` — centralized editable text and project data
- `script.js` — interactions, language switch, project galleries and lightbox
- `assets/` — official logo and project photography

## GitHub Pages
Upload the **contents of this folder** to the repository root, then enable:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

No Node.js, npm, Next.js, Vite or GitHub Actions are required.

## Editing content
For project order, project titles, descriptions, cover images and gallery images, edit `content.js`.
The first image in each project's `images` list is the cover image shown before opening the project.
